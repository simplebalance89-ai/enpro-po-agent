WHAT IT DOES
------------
Customer emails a PO (PDF attachment) to orders@enproinc.com. The agent:
- Pulls the email every 60 seconds via Graph API
- Parses the PDF with Azure Document Intelligence
- Matches the ship-to address to a P21 customer ID (95% auto-match rate)
- Matches each line item to a P21 inv_mast_uid via our crosswalk
- Scores confidence (green/yellow/red)
- Builds a P21 Transaction API v2 payload
- Operator reviews and clicks Approve → P21 creates the Sales Order

All rule-based algorithms. No LLM. No AI agent. No manual data entry.

This is exactly what I told Grant on day one: it's an API that reads emails, runs matching algorithms against our crosswalks, and builds a P21 payload. The design hasn't changed since that meeting.
